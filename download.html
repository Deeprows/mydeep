Does your phone say the file is harmful? That's expected.

Deeprowss isn't on Google Play yet. Android and Chrome show a warning for every app that is installed from outside the Play Store, whoever made it. The message is about where the file comes from, not about anything found inside it.

Keep going. Tap the option below that matches what you see:

  • Chrome "This file may be harmful" or "isn't commonly downloaded": tap Download anyway or Keep.
  • Android "For your security, your phone isn't allowed to install unknown apps from this source": tap Settings, switch on Allow from this source, then go back.
  • Play Protect "Blocked by Play Protect" or "App not scanned": tap More details, then Install anyway.

Only download Deeprowss from this page. Don't install copies sent by other people or found on other sites.

How to install

  1. Download the file

    Tap Download APK above. If it doesn't start, try the backup button. When Chrome warns you, tap Download anyway.

  2. Open it

    Open the notification when the download finishes, or find Deeprowss.apk in your Downloads folder (Files app) and tap it.

  3. Allow the install

    If Android asks, tap Settings and switch on Allow from this source for your browser or Files app. Press back to return to the installer.

  4. Tap Install

    If Play Protect interrupts, tap More details, then Install anyway. Wait for it to finish.

  5. Open Deeprowss

    Tap Open. You'll find the app in your app drawer from now on. Delete the APK file afterwards to free up space.

If something goes wrong

The download won't start

Use the backup button. If both fail, check your connection, switch between Wi-Fi and mobile data, or try another browser.

"App not installed"

The file probably didn't finish downloading. Delete it and download again. If you have an older copy of Deeprowss, uninstall it first.

I can't find "Install anyway"

Tap More details on the warning first. The option appears underneath. On some phones you may need to tap Install anyway twice.

How do I update the app?

Come back to this page, download the newest APK, and install it over your current version. Your settings stay.
